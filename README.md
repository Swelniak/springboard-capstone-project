# Springboard Capstone Project - Step 1: Initial Project Ideas

For my Springboard Capstone Project, I am interested in building a full-stack application that uses a combination of external API data and my own backend API. I want the final project to be useful, polished, and something I can include in my portfolio.

## Preferred Idea: GameLog - A Letterboxd-Style App for Video Games

GameLog would be a video game tracking application where users can search for games, save them to personal lists, rate them, review them, and track their progress. The idea is similar to Letterboxd, but focused on video games instead of movies.

Users would be able to organize games into categories such as “Want to Play,” “Currently Playing,” “Completed,” and “Dropped.” They could also leave personal notes, ratings, and reviews for each game. This would make the app useful for people who want to manage their gaming backlog and keep a record of the games they have played.

For data, I would explore using an external video game API such as RAWG to retrieve game titles, cover images, release dates, platforms, genres, and other game details. My own backend API would handle user accounts, saved games, ratings, reviews, and custom lists.

This is the idea I am most interested in building because it has clear user flows, a strong external data source, and plenty of room for full-stack features.

## Idea 2: SafePlate - Allergy-Aware Meal Prep App

SafePlate would be a meal prep and recipe planning application designed for people with serious food allergies. Many recipe apps allow users to search for meals, but it can still be difficult for people with life-threatening allergies to quickly find recipes that avoid specific ingredients.

Users would create an allergy profile and select ingredients or categories they need to avoid, such as seafood, nuts, or dairy. They could then search for recipes, save safe options, build a weekly meal plan, and create a grocery list. Users could also add personal notes to recipes, such as ingredient substitutions or reminders to check labels for cross-contamination risks.

For data, I would explore recipe APIs such as Edamam, Spoonacular, or TheMealDB. The external API would provide recipe information, while my own backend would manage user profiles, saved recipes, allergy preferences, meal plans, and grocery lists.

This project would solve a real-world problem and has personal meaning because food allergies can make meal planning stressful and time-consuming.

## Idea 3: ComicVault - Comic Book Collection Tracker

ComicVault would be a comic book collection tracker where users can search for comic books, save issues to their personal collection, create a wishlist, and track details about the comics they own.

Users could add comics to their collection and include personal information such as condition, purchase price, estimated value, notes, and favorite characters or series. They could also create a wishlist for comics they want to buy in the future.

For data, I would explore using a comic book API such as Comic Vine to retrieve comic titles, issue information, covers, publishers, characters, and release dates. My own backend API would handle user accounts, saved collection items, wishlists, notes, and personal collection data.

This project would be fun to build because it is visual, personal, and easy to demonstrate as a portfolio project.

## Current Preferred Choice

At this point, my preferred idea is GameLog, the Letterboxd-style video game tracker. I think this idea has the clearest user flows, a realistic scope for the capstone, and strong portfolio potential.
